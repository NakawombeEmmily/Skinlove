## File Dependencies & Data Flow

### Authentication Flow
```
frontend/script.js (handleLogin)
    ↓
POST /api/auth/login
    ↓
backend/routes/auth.js (login handler)
    ↓
User.js (schema + comparePassword)
    ↓
MongoDB (User collection)
    ↓
JWT token generated
    ↓
localStorage (save token + user)
    ↓
showMainApp() - Load main interface
```

### Skin Analysis Flow
```
frontend/script.js (submitQuiz)
    ↓
POST /api/skin/quiz
    ↓
backend/routes/skinAnalysis.js (quiz handler)
    ↓
determineSkinType() - Algorithm
    ↓
SkinAnalysis.js (create record)
    ↓
Product.js (query matching products)
    ↓
Results displayed in frontend
```

### Store Finder Flow
```
frontend/script.js (findNearbyStores)
    ↓
navigator.geolocation.getCurrentPosition()
    ↓
PUT /api/auth/profile (save coordinates)
    ↓
GET /api/stores/nearby
    ↓
backend/routes/stores.js
    ↓
calculateDistance() - Haversine formula
    ↓
Sort by distance
    ↓
Display stores to user
```

### Chatbot Flow
```
frontend/script.js (sendMessage)
    ↓
POST /api/chat/message
    ↓
backend/routes/chatbot.js
    ↓
Message keyword analysis
    ↓
Response selection
    ↓
Return to frontend
    ↓
Display message in chat box
```

1. **backend/models/Product.js** - Add product fields
2. **backend/routes/skinAnalysis.js** - Improve skin detection algorithm
3. **backend/routes/stores.js** - Add store filtering

### For Configuration
1. **backend/.env** - Database and server settings
2. **frontend/script.js** - API_BASE_URL for production
